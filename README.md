# Digital-Image-Processing-Toolkit





1. Color Channel Swap
Loads an RGB image, extracts individual color channels (R, G, B), and swaps the red and blue channels. Displays the original and channel-swapped images side-by-side for comparison.

2. Bitwise Image Operations
Demonstrates fundamental bitwise operations on binary images including AND, OR, XOR, and NOT operations. Creates a rectangle and circle, then applies various bitwise operations to show how they combine or manipulate binary image data.

3. Line Detection using Hough Transform
Detects lines in an image using the Canny edge detector followed by the Hough Line Transform. Draws the detected lines on the original image with a specified color and thickness.

4. Image Filtering and Histogram Analysis
Applies multiple filtering techniques (mean, median, and Gaussian blur) to an image and performs Otsu thresholding. Displays histograms for each filtered result and visualizes all processed images in a grid layout.

5. Edge Detection (Canny vs Sobel)
Compares two edge detection methods on a grayscale image. Applies Canny edge detection and Sobel filters (X and Y derivatives), then displays all three results in a horizontal subplot arrangement.

6. Face Detection using Haar Cascade
Uses OpenCV's pre-trained Haar Cascade classifier to detect faces in an image. Draws green rectangles around detected faces and displays the annotated result.

7. Morphological Operations
Applies various morphological operations (erode, dilate, open, close, cross) to a binary image using a 3×3 kernel. Visualizes all morphological transformations in a grid layout.

8. Histogram Equalization
Performs histogram equalization on a grayscale image to improve contrast. Displays the original and equalized images alongside their respective histograms for comparison.

9. Frequency Domain Filtering (Low-pass and High-pass)
Applies Fourier Transform to convert an image to the frequency domain, then applies low-pass and high-pass filters. Displays the original image and the results of both frequency-domain filtering techniques.
